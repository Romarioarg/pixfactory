# BUG-002 — Simulador calcula juros no frontend

| Campo | Conteúdo |
| --- | --- |
| **ID** | BUG-002 |
| **Severidade** | Alta |
| **Ambiente** | `simulador.html`, usuário autenticado |
| **Passos para Reproduzir** | 1. Abrir Simulador. 2. Valor 1000, taxa 2,5%, 12 parcelas. 3. Calcular. 4. Comparar o valor da parcela com um contrato Price criado em `novo_contrato.html` para o mesmo principal e taxa. |
| **Resultado Esperado** | A parcela da simulação vem da mesma regra do backend (precisão monetária única). |
| **Resultado Obtido** | `frontend/js/pages/simulador.js` aplica a fórmula Price em JavaScript (`Math.pow`). O contrato persistido usa outra rotina no servidor. Há risco de divergência por `double` e por frequência (semanal/diário). |
| **Evidência** | Screenshot do card Resultado (`#res-parcela`) ao lado da prévia de `novo_contrato.html` para R$ 1.000 / 2,5% / 12x, com valores diferentes na casa dos centavos. |
| **Status** | Aberto |
