# BUG-001 — Menu "+ Novo" do dashboard não abre destino confiável

| Campo | Conteúdo |
| --- | --- |
| **ID** | BUG-001 |
| **Severidade** | Média |
| **Ambiente** | `http://localhost:8080/dashboard.html` após login DEMO |
| **Passos para Reproduzir** | 1. Autenticar com `demo@pixfactory.app`. 2. No cabeçalho do dashboard, clicar no botão **+ Novo**. 3. Tentar acionar "Novo cliente" ou "Novo contrato" no menu dropdown. 4. Repetir em viewport 390px. |
| **Resultado Esperado** | O menu abre e os links levam a `cadastro.html` e `novo_contrato.html`. |
| **Resultado Obtido** | O dropdown depende de hover/CSS (`.dropdown-menu`). Em toque ou clique rápido o menu fecha antes do navegador seguir o link, ou não abre. |
| **Evidência** | Screenshot do cabeçalho do dashboard com o botão "+ Novo" expandido/colapsado e o cursor sobre o item, URL ainda em `dashboard.html`. |
| **Status** | Aberto |
