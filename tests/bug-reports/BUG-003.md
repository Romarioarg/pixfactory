# BUG-003 — USER recebe 403 em /api/users sem feedback na UI de gerenciamento

| Campo | Conteúdo |
| --- | --- |
| **ID** | BUG-003 |
| **Severidade** | Baixa |
| **Ambiente** | Login `demo@pixfactory.app` (role USER) |
| **Passos para Reproduzir** | 1. Autenticar como USER. 2. Navegar manualmente para `gerenciamento_usuarios.html`. 3. Observar a lista. 4. Conferir GET `/api/users` no Network. |
| **Resultado Esperado** | A tela informa que a área é restrita a ADMIN, ou o layout redireciona. |
| **Resultado Obtido** | A API responde 403 (`Você não tem permissão para esta ação.`). A página de gerenciamento não explica a recusa; o item Usuários só entra no menu para ADMIN, mas a URL direta falha de forma opaca. |
| **Evidência** | Screenshot do Network com 403 em `/api/users` e da página de usuários vazia/erro genérico, com a sidebar USER sem o item Usuários. |
| **Status** | Aberto |
