PIXFACTORY

Projeto de portfólio com frontend, API e MySQL

Esta página no GitHub Pages é a vitrine pública do PixFactory. O sistema completo (login, dashboard, clientes, contratos, Pix Demo) precisa do backend Spring Boot e não roda só neste endereço estático.

Ver repositório no GitHub README e instalação

O que o projeto demonstra

  • HTML, CSS e JavaScript
  • Java, Spring Boot, API REST, JPA e MySQL
  • CRUD, autenticação JWT e autorização ADMIN/USER
  • Pix Demo, Open Finance Demo e e-mail Demo (mocks substituíveis)
  • Docker, Swagger e testes

Como executar o sistema

Com Docker:

git clone https://github.com/Romarioarg/pixfactory.git
cd pixfactory
docker compose up --build

Depois abra http://localhost:8080

Conta demo: demo@pixfactory.app / Demo@123

Admin demo: admin@pixfactory.app / Admin@123

Links antigos de currículo como /dashboard.html agora abrem esta vitrine, porque o dashboard real passou a exigir login na API.
